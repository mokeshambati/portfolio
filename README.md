# Mokesh Ambati — Cloud & DevOps Portfolio

A responsive, multi-page static portfolio inspired by the uploaded reference design and tailored to the uploaded resume.

## Pages
- `index.html` — Home / hero / selected projects
- `about.html` — About, education, and training
- `skills.html` — Skills grouped by domain
- `projects.html` — Detailed project write-ups with GitHub links
- `contact.html` — Email, GitHub, LinkedIn

## Quick start
1. Extract the ZIP.
2. Open `index.html` in your browser, or use VS Code **Live Server** for a local preview.
3. Replace the photo placeholder as described below.

## Add your photo
- Prepare a professional headshot named **`profile-photo.jpg`**.
- Put it inside the `assets` folder, replacing the placeholder instructions.
- The home page will automatically display it in the hero frame. The About page currently uses a designed placeholder; you can change that area to use the same image if you want.

## Resume download
The included resume PDF is stored at `assets/Ambati-Mokesh-Reddy-Resume.pdf`. Replace it with your latest version using the same filename when updating your resume.

## Customize
- Update your email / social links in the HTML if needed.
- Styling lives in `css/style.css`.
- Responsive navigation and current year live in `js/main.js`.
- This is a static HTML/CSS/JavaScript website; no build step or framework is required.
- Google Fonts require an internet connection; system font fallbacks are included.

## Publish
You can host this folder on GitHub Pages, Netlify, or any static web host. Upload the extracted files with `index.html` at the site root.


## Recent updates
- White/light theme is the default; use the header theme toggle to switch to dark mode. Your choice is saved in the browser.
- The Contact page's Gmail action opens a Gmail compose window addressed to ambatimokeshreddy@gmail.com. A fallback link opens the device's default email app.
