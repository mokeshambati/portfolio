# Ambati Mokesh Reddy — Cloud & DevOps Portfolio

A responsive multi-page portfolio built with semantic HTML, CSS and vanilla JavaScript.

## Pages

- Home — concise recruiter overview, verified metrics and featured work
- About — career direction, education and certifications
- Skills — searchable technical toolkit
- Projects — filterable AWS, Azure and DevOps case studies
- Resume — embedded preview and downloadable PDF
- Contact — validated mailto form and direct contact links

## Run locally

Open `dist/index.html` directly or serve `dist` with any static web server.

## Customize

- Update shared navigation/footer in `dist/assets/js/components.js`.
- Update interaction logic in `dist/assets/js/main.js`.
- Replace the resume at `dist/assets/docs/Ambati-Mokesh-Reddy-Resume.pdf` while keeping the filename.
- Edit colors and layout tokens at the top of `dist/assets/css/style.css`.

## Deploy

The `dist` folder can be deployed to GitHub Pages, Netlify, Azure Static Web Apps or any static hosting platform.

## Contact and AI notes

The contact form uses `mailto:` and stores no data. The portfolio assistant is intentionally offline and answers only from verified portfolio content. To connect a real AI service later, create a secure server-side endpoint; never expose an API key in browser JavaScript.
